# شعبة الاستفسارات والشكاوى

نظام عربي **محلي** لإدارة الشكاوى — SQLite + واجهة ويب + **ملف سطح مكتب واحد**.

**الإصدار: 0.7.8**

> تحذير: لا تُدخل بيانات مواطنين حقيقية قبل مراجعة أمنية. انظر [SECURITY.md](SECURITY.md).

## للمستخدم: ملف EXE واحد (بدون Node.js)

بعد بناء النسخة المحمولة ورفعها في Releases:

1. نزّل `complaints-system-*-portable.exe`
2. اضغط مرتين → يعمل
3. **لا يحتاج** تثبيت Node.js على الجهاز

البيانات تُحفظ في `%APPDATA%` — استبدال الـ exe لا يمسح الشكاوى.

التفاصيل: [docs/UPDATE_AND_DATA.md](docs/UPDATE_AND_DATA.md)

### بناء الملف (جهاز المطوّر — Windows)

```bash
git pull
npm install
npm run dist:win
```

المخرج: `dist-desktop/complaints-system-0.7.8-portable.exe`

## للمطوّر: تشغيل من المصدر

```bash
npm install
cp .env.example .env
npm start
```

→ http://127.0.0.1:3000

أو نافذة سطح مكتب للتطوير: `npm run start:desktop`

## نسخة Windows والتشغيل المحلي

راجع [دليل إصدار Windows والاستعادة](docs/RELEASE_WINDOWS.md) لتنزيل آخر EXE ناجح، وتحديد مكان البيانات، وإنشاء نسخة احتياطية مشفّرة `.csb` تشمل المرفقات. لا يعني وجود الشيفرة على `main` أن اختبار EXE على جهاز Windows قد اكتمل.

## خط واجهة النظام

يستخدم التطبيق **Thmanyah Sans** كخط واجهة أول عند تثبيته على جهاز Windows. ملفات الخط نفسها غير مضمنة في المستودع لأسباب ترخيصية. اقرأ [طريقة تثبيت خط ثمانية](docs/FONT_THMANYAH.md).


## إعادة تصميم الواجهة (فرع التطوير)

فُصل المصدر القديم `app.full.js` إلى 15 ملفًا داخل `ui/` وفق الصفحات والإجراءات والأحداث. يجمعها `lib/ui-bundle.js` في `/app.bundle.js`، مع بقاء الخادم وSQLite دون تغيير. أصبحت تفاصيل الشكوى صفحة عمل مستقلة داخل التطبيق وتدعم الرجوع والرابط المحلي. تحقق من `npm run check` و`npm test` وبناء Windows وجرّب الواجهة قبل دمج PR #57.
