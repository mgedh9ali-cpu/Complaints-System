# شعبة الاستفسارات والشكاوى

نظام عربي **محلي** لإدارة الشكاوى — يعمل على اللابتوب مع SQLite، جلسات محفوظة، مرفقات، وتقارير Excel.

**الإصدار الحالي: 0.7.1**

## طريقة التشغيل (مهم)

هذا **ليس** ملف `.exe` مستقل مثل تطبيقات سطح المكتب.

هو **خادم محلي + واجهة في المتصفح**:

1. تشغّل الخادم على الجهاز
2. تفتح الواجهة على `http://127.0.0.1:3000`
3. لا يحتاج إنترنت بعد تجهيز الحزم مرة واحدة

### على Windows (مسار واحد)

بعد تثبيت Node.js 20.6+ وتثبيت الحزم (`npm install`) مرة واحدة:

1. انقر نقراً مزدوجاً على **`start-windows.bat`**
2. السكربت يجهّز الإعدادات عند أول تشغيل إن لزم
3. يشغّل الخادم
4. **يفتح المتصفح تلقائياً** عند جاهزية `http://127.0.0.1:3000`

الملفات المساعدة:
- `start-windows.bat` — التشغيل
- `open-local-browser.ps1` — انتظار الجاهزية ثم فتح المتصفح
- `scripts/initialize-local-config.js` — إنشاء `.env` محلي في أول تشغيل

### من سطر الأوامر

```bash
npm install
npm start
```

ثم افتح: http://127.0.0.1:3000

### متغيرات البيئة (`.env`)

```
SESSION_SECRET=...          # 32 حرف على الأقل
ADMIN_USERNAME=admin
ADMIN_PASSWORD=...
AUTO_BACKUP_HOURS=6         # 0 لإيقاف النسخ التلقائي
```

## ملاحظات أمنية

- النظام يستمع على `127.0.0.1` فقط (لا على الشبكة)
- لا تُدخل بيانات مواطنين حقيقية قبل مراجعة أمنية
- المرفقات في `data/attachments/`

## ما ليس ضمن النطاق الحالي

- **لا** يوجد مثبّت Windows بصيغة EXE / تطبيق Electron
- الواجهة تُستخدم عبر المتصفح مع الخادم المحلي
