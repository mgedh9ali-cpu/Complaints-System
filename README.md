# شعبة الاستفسارات والشكاوى

مستودع تطوير نموذج أولي للوحة إدارة الاستفسارات والشكاوى.

## نطاق المرحلة الأولى

- واجهة عربية RTL بطابع مؤسسي سوري محايد، دون اختلاق شعار رسمي.
- بيانات تجريبية فقط؛ لا تُدخل بيانات مواطنين حقيقية.
- إدارة تجريبية لسير الشكوى والإحالات والردود والملاحظات وسجل الأحداث.
- بحث عربي مطبّع، عروض محفوظة، إشعارات داخلية وتقارير تشغيلية أولية.
- لا يتضمن هذا النموذج مصادقة إنتاجية أو قاعدة بيانات مشتركة أو تشفيرًا معتمدًا أو إرسالًا رسميًا.

## تشغيل النموذج

افتح `index.html` في متصفح حديث. تُحفظ تغييرات النموذج محليًا في المتصفح لأغراض التجربة فقط، ولا تتم مزامنتها بين المستخدمين أو الأجهزة.

## تنبيه أمني

هذا نموذج واجهة أولي وليس نظامًا حكوميًا جاهزًا للتشغيل. لا تستخدم بيانات شخصية حقيقية. قبل التشغيل الفعلي يجب اعتماد بنية الاستضافة والوصول، والمصادقة الثنائية، والصلاحيات على الخادم، وسجل التدقيق غير القابل للتلاعب، والتشفير والنسخ الاحتياطي وسياسات الاحتفاظ من الجهة المختصة.
