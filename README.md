# شعبة الاستفسارات والشكاوى

مرشح الإصدار **1.0.0-rc.11** لنظام عربي محلي: Node/Express، SQLite، وواجهة سطح مكتب Electron.

يعمل الخادم على `127.0.0.1` فقط. لا يوفر هذا الإصدار قاعدة مشتركة عبر الإنترنت، ولا تكامل واتساب أو تلغرام آليًا؛ تُسجل القنوات يدويًا.

## ما يتوفر في المرشح

- حساب مالك محلي واحد، تغيير كلمة المرور وإبطال الجلسات، وتحقق ثنائي TOTP اختياري مع رموز استرداد.
- أرقام شكاوى سنوية متسلسلة، حفظ غير مكتمل، استكمال البيانات، ملاحظات وإحالات وردود جهات.
- انتقالات حالة مضبوطة، أسباب للإغلاق والإلغاء وإعادة الفتح، واستثناء إغلاق الإحالات بصلاحية مستقلة.
- مسودة رد ومراجعة واعتماد مسجل من حساب المالك؛ يثبت النص بعد الاعتماد ويُسجل الإرسال كإجراء مستقل.
- طلبات موافقة منفصلة للأرشفة وحذف المرفقات والإلغاء بعد إجراء رسمي وربط التكرار. لا يُحذف سجل الشكوى نهائيًا.
- تشفير محتوى الشكاوى والتدقيق والمرفقات بـAES-256-GCM. تبقى بنية SQLite وبعض البيانات الوصفية خارج التشفير؛ يلزم حماية مفاتيح الجهاز والقرص.
- نسخ كاملة مشفرة متحقق منها، جدولة كل 15 دقيقة أثناء التشغيل، واحتفاظ بالنسخ التلقائية ضمن آخر 7 أيام أثناء التشغيل. استيراد المزامنة يعرض معاينة وينشئ نسخة أمان قبل الاستبدال.
- تقارير CSV وExcel وPDF عربي متعدد الصفحات، وخط ثمانية مرفق محليًا للواجهة؛ يستخدم PDF خط Noto Sans Arabic.

### تحسينات المكتب (rc.11)

- مهلتان ظاهرتان: أول رد (افتراضي 48 ساعة) ومهلة الحل (`slaDays`).
- طوابير عمل: متأخرة، مهددة بالتأخر (≥75٪)، تأخر أول رد، بيانات ناقصة، إحالات، اعتمادات.
- قصة السجل في صفحة الملف + إغلاق منظم (سبب جذري، إجراء، قناة إبلاغ).
- كشف تكرار بالهاتف أو بالاسم والتصنيف، ووضع استقبال لتسجيل سريع.
- التفاصيل: [docs/DESK_UX_1_TO_5.md](docs/DESK_UX_1_TO_5.md).

## التشغيل من المصدر

```bash
npm ci --ignore-scripts
npm run check:sqlite
node scripts/initialize-local-config.js
npm run check
npm test
npm start
```

احفظ بيانات أول مدير التي تظهر من أداة التهيئة. لا تشارك `.env` ولا ترفعه إلى المستودع. يتطلب التشغيل Node 22 أو أحدث؛ تستخدم اختبارات CI الإصدار Node 24.

## Windows

```bash
npm ci
npm run dist:win
```

للتشغيل اليومي الأسرع: استخدم `dist-desktop/complaints-system-1.0.0-rc.11-setup.exe` للتثبيت في حساب Windows الحالي، ثم افتح البرنامج من اختصار سطح المكتب. تبقى البيانات في مجلد المستخدم نفسه عند الانتقال من النسخة المحمولة.

تُنشر نسخة تثبيت واحدة فقط في صفحة الإصدارات. تبقى النسخة المحمولة ضمن ملفات التحقق الداخلية لاختبارات البناء. لا يلزم تثبيت Node.js على جهاز الاستخدام. يُختبر تثبيت الحزمة مرتين في المسار نفسه قبل النشر.

## تحقق الاعتماديات والتغليف

يُفحص تحميل خط ثمانية واستخدامه فعليًا في Chromium ضمن اختبارات الحزمة قبل نشر ملف التثبيت.

عالج تحديث 2026-11-09 تنبيهات الاعتماديات المعروفة وقت الفحص. تبقى بعض الحزم الانتقالية مهجورة وتحتاج متابعة مستقلة. تستخدم التبعيات القديمة محولات استدعاء صغيرة موثقة في [vendor/README.md](vendor/README.md)، بينما تنفذ المطابقةَ المكتباتُ الرسمية المصححة. يلزم تضمين `vendor/` عند جلب المصدر؛ يثبته `npm ci` وفق ملف القفل.

يفحص CI شجرة التبعيات كاملة ويفشل عند أي تنبيه أمني بدءًا من الدرجة المنخفضة. تستخدم الحزمة ASAR مع فك الملفات الأصلية اللازمة لـ SQLite. يضيف مسار Windows تشغيل EXE وفحص الدخول والكتابة والتصدير في ملف مستخدم اختبار معزول؛ لا يغني ذلك عن قبول الواجهة والطباعة والاستعادة على جهاز المستخدم.
