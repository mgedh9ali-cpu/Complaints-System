# شعبة الاستفسارات والشكاوى

نظام عربي محلي لإدارة الشكاوى — يعمل على اللابتوب مع SQLite، جلسات محفوظة، مرفقات، وتقارير Excel.

## تشغيل النظام

```bash
git pull
npm install
npm test
npm start
```

ثم افتح: http://127.0.0.1:3000

```

ADMIN_USERNAME=admin
```

## المرفقات

- **رفع:** `POST /api/attachments/:complaintId` (multipart, حقل `files`)
- **تنزيل:** `GET /api/attachments/:storedName`
- **حذف:** `DELETE /api/attachments/:storedName`
- الأنواع المسموحة: PDF, صور (jpg/png/webp/gif), Word, Excel, نص
- الحد الأقصى: 5 ملفات × 5 ميجابايت لكل شكوى
- من الواجهة: استخدم `window.__uploadAttachments(complaintId, fileList)`

## تصدير Excel

- من الواجهة: زر **📊 Excel** في الشريط العلوي
- أو مباشرة: `GET /api/export/xlsx`
- الملف يحتوي: الرقم المرجعي، الاسم، الهاتف، المحافظة، الجهة، التصنيف، الأولوية، الحالة، الملخص، التواريخ، المسؤول
- منسق RTL مع عنوان وتصفية تلقائية

## ملاحظات أمنية

- النظام يعمل على `127.0.0.1` فقط (لا يستمع على الشبكة)
- لا تُدخل بيانات مواطنين حقيقية قبل مراجعة أمنية
- المرفقات تُخزَّن محلياً في `data/attachments/`
