# شعبة الاستفسارات والشكاوى

واجهة عربية لإدارة الشكاوى، مع خادم محلي وقاعدة بيانات SQLite تعمل على اللابتوب.

**الإصدار الحالي: 0.4.0**

## الميزات الرئيسية في 0.4.0

| الميزة | الحالة |
|--------|--------|
| جلسات محفوظة على القرص (session-file-store) | ✅ |
| حماية CSRF على المسارات الحساسة | ✅ |
| تصدير الشكاوى إلى CSV (مع دعم العربية) | ✅ |
| نسخ احتياطي تلقائي كل 6 ساعات | ✅ |
| حفظ رأس سلسلة التدقيق في ملف منفصل | ✅ |
| تحقق أقوى من مدخلات الشكاوى | ✅ |
| PWA (manifest + Service Worker) | ✅ |
| زر تصدير CSV في الواجهة | ✅ |
| إشعارات المتصفح عند اقتراب انتهاء SLA | 🔄 جاهز للتفعيل |
| بحث متقدم (هاتف / رقم مرجعي / تاريخ) | 🔄 جاهز للتفعيل |

## تشغيل النظام

1. ثبّت Node.js 20.6+.
2. انسخ `.env.example` إلى `.env` وعدّل القيم.
3. `npm install`
4. `npm test`
5. `npm start`
6. افتح `http://127.0.0.1:3000`

### متغيرات بيئة إضافية

```
AUTO_BACKUP_HOURS=6          # 0 لإيقاف النسخ التلقائي
COOKIE_SECURE=false          # true فقط مع HTTPS
```

## استخدام CSRF من الواجهة

بعد تسجيل الدخول اجلب الرمز:
```js
const { csrfToken } = await api('/api/csrf');
// ثم أرسله مع كل طلب تعديل:
headers: { 'X-CSRF-Token': csrfToken }
```

## تصدير CSV

- من الواجهة: زر «تصدير CSV» (يظهر بعد تسجيل الدخول).
- أو مباشرة: `GET /api/export/csv` (يتطلب صلاحية admin/staff/reviewer).

## PWA

- يمكن تثبيت التطبيق كتطبيق سطح مكتب/موبايل.
- الأصول الثابتة تُخزَّن مؤقتاً للعمل دون اتصال (الـ API يحتاج الخادم المحلي).

## حدود مهمة

هذا إصدار تطوير محلي. لا تُدخل بيانات مواطنين حقيقية قبل مراجعة أمنية. الجلسات والبيانات محلية فقط.

## أفكار لاحقة

- تفعيل إشعارات المتصفح بالكامل عند اقتراب انتهاء مهلة SLA.
- بحث متقدم في الواجهة.
- وضع مراجعة مقيد أكثر لدور reviewer.
- اختبارات Playwright.
