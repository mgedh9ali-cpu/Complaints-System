# شعبة الاستفسارات والشكاوى

نظام عربي **محلي** لإدارة الشكاوى — يعمل على اللابتوب مع SQLite، جلسات محفوظة، مرفقات، وتقارير Excel.

**الإصدار الحالي: 0.7.2**

## طريقة التشغيل

### 1) تطبيق سطح المكتب (موصى به على Windows)

يفتح **نافذة مستقلة** (Electron) بدون أن تبحث عن المتصفح يدوياً، مع تشغيل الخادم المحلي في الخلفية.

المتطلبات: Node.js 20.6+ مرة واحدة، ثم:

1. `npm install`
2. انقر **`start-desktop.bat`**  
   أو: `npm run start:desktop`

عند أول تشغيل يُنشأ ملف `.env` محلياً وتظهر بيانات المدير إن كانت جديدة.

بناء ملف محمول (portable) لـ Windows:

```bash
npm run dist:win
```

المخرجات في مجلد `dist-desktop/`.

> ملاحظة: الغلاف سطح مكتب؛ المحرك ما زال الخادم المحلي على `127.0.0.1` فقط.

### 2) متصفح عادي (بدون Electron)

1. انقر **`start-windows.bat`**
2. أو: `npm start` ثم افتح http://127.0.0.1:3000

### متغيرات البيئة (`.env`)

```
SESSION_SECRET=...          # 32 حرف على الأقل
ADMIN_USERNAME=admin
ADMIN_PASSWORD=...
AUTO_BACKUP_HOURS=6         # 0 لإيقاف النسخ التلقائي
```

## ملاحظات أمنية

- النظام يستمع على `127.0.0.1` فقط (لا على الشبكة)
- لا تُدخل بيانات مواطنين حقيقية قبل مراجعة أمنية
- المرفقات في `data/attachments/`
- ملف `.env` خاص بالجهاز ولا يُرفع للمستودع
