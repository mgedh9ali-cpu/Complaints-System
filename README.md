# شعبة الاستفسارات والشكاوى

مرشح الإصدار **1.0.0-rc.1** لنظام عربي محلي: Node/Express، SQLite، وواجهة سطح مكتب Electron.

يعمل الخادم على `127.0.0.1` فقط. لا يوفر هذا الإصدار قاعدة مشتركة عبر الإنترنت، ولا تكامل واتساب أو تلغرام آليًا؛ تُسجل القنوات يدويًا.

## ما يتوفر في المرشح

- حسابات محلية، صلاحيات فردية، تغيير كلمة المرور وإبطال الجلسات، وتحقق ثنائي TOTP اختياري مع رموز استرداد.
- أرقام شكاوى سنوية متسلسلة، حفظ غير مكتمل، استكمال البيانات، مسؤول رئيسي ومساعدون، ملاحظات وإحالات وردود جهات.
- انتقالات حالة مضبوطة، أسباب للإغلاق والإلغاء وإعادة الفتح، واستثناء إغلاق الإحالات بصلاحية مستقلة.
- مسودة رد ومراجعة واعتماد من شخص آخر؛ لا يستطيع المؤلف أو آخر محرر اعتماد الرد، ويثبت النص بعد الاعتماد.
- طلبات موافقة منفصلة للأرشفة وحذف المرفقات والإلغاء بعد إجراء رسمي وربط التكرار. لا يُحذف سجل الشكوى نهائيًا.
- تشفير محتوى الشكاوى والتدقيق والمرفقات بـAES-256-GCM. تبقى بنية SQLite وبعض البيانات الوصفية خارج التشفير؛ يلزم حماية مفاتيح الجهاز والقرص.
- نسخ كاملة مشفرة متحقق منها، جدولة كل 15 دقيقة أثناء التشغيل، واحتفاظ يومي 30 يومًا. استيراد المزامنة يعرض معاينة وينشئ نسخة أمان قبل الاستبدال.
- تقارير CSV وExcel وPDF عربي متعدد الصفحات، وخط Noto Sans Arabic محلي مرخص عند غياب خط ثمانية المثبت.

## التشغيل من المصدر

```bash
npm ci --ignore-scripts
npm rebuild better-sqlite3
node scripts/initialize-local-config.js
npm run check
npm test
npm start
```

احفظ بيانات أول مدير التي تظهر من أداة التهيئة. لا تشارك `.env` ولا ترفعه إلى المستودع. يتطلب التشغيل Node 22 أو أحدث؛ تستخدم اختبارات CI الإصدار Node 24.

## Windows

```bash
npm ci
npm run dist:win
```

الملف المستهدف: `dist-desktop/complaints-system-1.0.0-rc.1-portable.exe`. لا يحتاج جهاز المستخدم إلى Node بعد بناء الملف. لا يعني هذا المسار أن بناء EXE أو قبوله على Windows قد تم؛ راجع نتيجة Actions المرتبطة بالالتزام النهائي ودليل الإصدار.
