# شعبة الاستفسارات والشكاوى

مرشح الإصدار **1.0.0-rc.8** لنظام عربي محلي: Node/Express، SQLite، وواجهة سطح مكتب Electron.

يعمل الخادم على `127.0.0.1` فقط. لا يوفر هذا الإصدار قاعدة مشتركة عبر الإنترنت، ولا تكامل واتساب أو تلغرام آليًا؛ تُسجل القنوات يدويًا.

## ما يتوفر في المرشح

- حساب مالك محلي واحد، تغيير كلمة المرور وإبطال الجلسات، وتحقق ثنائي TOTP اختياري مع رموز استرداد.
- أرقام شكاوى سنوية متسلسلة، حفظ غير مكتمل، استكمال البيانات، ملاحظات وإحالات وردود جهات.
- انتقالات حالة مضبوطة، أسباب للإغلاق والإلغاء وإعادة الفتح، واستثناء إغلاق الإحالات بصلاحية مستقلة.
- مسودة رد ومراجعة واعتماد مسجل من حساب المالك؛ يثبت النص بعد الاعتماد ويُسجل الإرسال كإجراء مستقل.
- طلبات موافقة منفصلة للأرشفة وحذف المرفقات والإلغاء بعد إجراء رسمي وربط التكرار. لا يُحذف سجل الشكوى نهائيًا.
- تشفير محتوى الشكاوى والتدقيق والمرفقات بـAES-256-GCM. تبقى بنية SQLite وبعض البيانات الوصفية خارج التشفير؛ يلزم حماية مفاتيح الجهاز والقرص.
- نسخ كاملة مشفرة متحقق منها، جدولة كل 15 دقيقة أثناء التشغيل، واحتفاظ بالنسخ التلقائية ضمن آخر 7 أيام أثناء التشغيل. استيراد المزامنة يعرض معاينة وينشئ نسخة أمان قبل الاستبدال.
- تقارير CSV وExcel وPDF عربي متعدد الصفحات، وخط ثمانية مرفق محليًا للواجهة؛ يستخدم PDF خط Noto Sans Arabic.

## التشغيل من المصدر

```bash
npm ci --ignore-scripts
npm run check:sqlite
node scripts/initialize-local-config.js
npm run check
npm test
npm start
```

احفظ بيانات أول مدير التي تظهر من أداة التهيئة. لا تشارك `.env` ولا ترفعه إلى المستودع. يتطلب التشغيل Node 22 أو أحدث؛ تستخدم اختبارات CI الإصدار Node 24.

## Windows

```bash
npm ci
npm run dist:win
```

للتشغيل اليومي الأسرع: استخدم `dist-desktop/complaints-system-1.0.0-rc.8-setup.exe` للتثبيت في حساب Windows الحالي، ثم افتح البرنامج من اختصار سطح المكتب. تبقى البيانات في مجلد المستخدم نفسه عند الانتقال من النسخة المحمولة.

تُنشر نسخة تثبيت واحدة فقط في صفحة الإصدارات. تبقى النسخة المحمولة ضمن ملفات التحقق الداخلية لاختبارات البناء. لا يلزم تثبيت Node.js على جهاز الاستخدام. يُختبر تثبيت الحزمة مرتين في المسار نفسه قبل النشر.

## تحقق الاعتماديات والتغليف

يُفحص تحميل خط ثمانية واستخدامه فعليًا في Chromium ضمن اختبارات الحزمة قبل نشر ملف التثبيت.

عالج تحديث 2026-11-09 تنبيهات الاعتماديات المعروفة وقت الفحص. تبقى بعض الحزم الانتقالية مهجورة وتحتاج متابعة مستقلة. تستخدم التبعيات القديمة محولات استدعاء صغيرة موثقة في [vendor/README.md](vendor/README.md)، بينما تنفذ المطابقةَ المكتباتُ الرسمية المصححة. يلزم تضمين `vendor/` عند جلب المصدر؛ يثبته `npm ci` وفق ملف القفل.

يفحص CI شجرة التبعيات كاملة ويفشل عند أي تنبيه أمني بدءًا من الدرجة المنخفضة. تستخدم الحزمة ASAR مع فك الملفات الأصلية اللازمة لـSQLite. يضيف مسار Windows تشغيل EXE وفحص الدخول والكتابة والتصدير في ملف مستخدم اختبار معزول؛ لا يغني ذلك عن قبول الواجهة والطباعة والاستعادة على جهاز المستخدم.

## وارد واتساب أعمال

1. من واتساب أعمال، صدّر المحادثة مع الوسائط. فك ضغط ملف التصدير إن أُرسل بصيغة ZIP.
2. في نافذة تسجيل سجل جديد افتح «وارد واتساب»، واختر ملف TXT وترتيب التاريخ، ثم اضغط «قراءة المحادثة».
3. اختر مرسل الطلب وحدد الوسائط المطلوبة في السجل. تظهر أزرار تشغيل التسجيلات المطابقة لأسماء ملفات Opus أو Ogg. يمكن كتابة التفريغ أثناء الاستماع.
4. اضغط «معاينة الملخص»، وراجع المقتطفات والنوع المقترح وأول تاريخ ظاهر. عدّل النص قبل نقله إلى نموذج التسجيل. يمكنك إرفاق ملف TXT الأصلي لحفظ كامل المحادثة، وإرفاق النص الكامل لتفريغ التسجيلات في ملف مستقل.
5. راجع النموذج واحفظه. يدعم السجل حتى خمسة مرفقات، حجم كل منها حتى 5 ميغابايت. السجل المحفوظ يتيح تشغيل الصوت من قسم المرفقات.

بيانات الاستيراد تبقى في نافذة التسجيل حتى الحفظ الصريح. إدارة المرفقات بعد الحفظ تستخدم مسار المرفقات المشفّر الموجود في النظام. قراءة المحادثة وتلخيصها وتجهيز المرفقات تتم محليًا دون اشتراك أو اتصال بواتساب من داخل البرنامج.

### تفعيل التفريغ العربي الآلي محليًا (اختياري)

ثبّت FFmpeg وإصدارًا حديثًا من [whisper.cpp](https://github.com/ggml-org/whisper.cpp) يدعم استقبال WAV من الإدخال القياسي، ونزّل نموذجًا متعدد اللغات مثل ggml-base.bin. أضف المسارات المطلقة إلى ملف .env في مجلد بيانات التطبيق لنسخة سطح المكتب، أو ملف .env الذي يحمّله الخادم، ثم أعد التشغيل. مثال Windows:

    WHATSAPP_FFMPEG_PATH=C:\Tools\ffmpeg\bin\ffmpeg.exe
    WHATSAPP_WHISPER_PATH=C:\Tools\whisper\whisper-cli.exe
    WHATSAPP_WHISPER_MODEL=C:\Tools\whisper\models\ggml-base.bin

بعد الإعداد، يظهر زر «تفريغ آلي بالعربية» بجانب التسجيل المطابق. يشغّل التطبيق أدوات التفريغ محليًا دون إرسال الصوت إلى الإنترنت ودون كتابة نسخة وسيطة على القرص. التفريغ الآلي يقبل تسجيلات Opus/Ogg حتى خمس دقائق وحتى 5 ميغابايت لكل تسجيل. راجع النص مقابل التسجيل قبل إدخاله في الملخص.
