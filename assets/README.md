# Noto Sans Arabic

`NotoSansArabic.ttf` merges the unmodified Arabic and Latin 400-normal font tables from Fontsource Noto Sans Arabic 5.3.0 for offline UI/PDF rendering. It was produced with FontTools Merger and saved as TrueType. The original copyright and SIL Open Font License are included in `NotoSansArabic-OFL.txt`.

Source: https://fontsource.org/fonts/noto-sans-arabic
Upstream: https://github.com/notofonts/arabic

This font is separate from the locally installed, licensed Thmanyah font; Thmanyah files are not redistributed.
