# إصلاحات مراجعة 9 نوفمبر 2026

تُطبق التغييرات على قاعدة البيانات الحالية دون حذفها أو إعادة إنشاء الحسابات.

## الردود والصلاحيات
- تستخدم واجهة الرد المخصصة وحفظ الحالة القديم تحققًا مشتركًا للصلاحيات وانتقالات الرد.
- يمنع إعادة الرد المعتمد أو المرسل إلى المراجعة، وتغيير النص أثناء الاعتماد، واعتماد الكاتب أو آخر محرر لرده.
- تسجل هوية الكاتب والمحرر والمعتمد ووقت الاعتماد والإرسال على الخادم. تبقى طلبات العملاء القديمة التي تحذف حقول الهوية متوافقة مع استعادة القيم الموثوقة المحفوظة.
- تبقى انتقالات المراجعة ثم الاعتماد من شخص مختلف ثم توثيق الإرسال متاحة.

## البيانات والتدقيق
- يفشل الحفظ قبل التعديل عند تعذر حساب فروق التدقيق.
- لا يبدأ الخادم إذا كشف سجل تدقيق تالفًا؛ يلزم الاستعادة من نسخة متحقق منها.
- تُشفّر نصوص التذكيرات بسياق معرّف التذكير، وتُرحّل النصوص القديمة عند فتح قواعد البيانات القديمة أو المشفرة سابقًا.
- يلتزم حفظ التذكير أو إيقافه مع حدث التدقيق في معاملة واحدة.

## الأداء والعرض
- يتجاوز تحديث فهرس الشكاوى السجلات غير المتغيرة دون فك تشفير كل سجل أو استعلام مستقل عنه.
- تستخدم معالجة تذكير الاستكمال الفترة المحددة في الإعدادات، بين ساعة و720 ساعة.
- تُحمّل أسماء المسؤولين من مسار الموظفين المصرح به، وتظل إدارة الحسابات خاصة بالمدير.
- تستخدم المؤشرات في الوضع الداكن لون النص الأساسي بدل لون الخلفية الأخضر الداكن.
- حُفظ تحديث خط ثمانية المرفوع إلى المستودع أثناء العمل.

## النسخ والاعتماديات
- لا تُمنح علامة التحقق لنسخة اعتمادًا على امتداد الملف؛ تُربط نتيجة الفحص الفعلي بهوية الملف وحجمه وأوقاته وتزول عند تغييره.
- سياسة الاحتفاظ الحالية سبعة أيام للنسخ التلقائية؛ صُحح README ليتفق مع التنفيذ. لا يحذف هذا التعديل النسخ اليدوية.
- تستخدم GitHub Actions تثبيت npm ci، وتفشل عند أخطاء شجرة الاعتماديات أو نتائج تدقيق الأمان.
- تُضبط الإصدارات المصححة مع الحفاظ على واجهات أدوات المقارنة والتغليف القديمة، دون تعطيل اختبارات التوافق.

النسخ التلقائي يعمل أثناء تشغيل التطبيق. اختيار مجلد خارجي معتمد وحفظ مفتاح الاستعادة منفصلًا يظلان إعدادين تشغيليين ينفذهما المدير من قائمة النسخ والاستعادة. لا يغيّر هذا الإصلاح مجلد بيانات المستخدم أو يمحو ملفات النسخ المحمولة القديمة.

## نتيجة التحقق
- Node 24: نجح 281 اختبارًا دون فشل أو تجاوز.
- نجح npm ci وnpm ls --all وnpm run check وnpm run check:sqlite.
- أظهر npm audit --audit-level=low صفر نتائج معروفة وقت الفحص.
- حفظ تعديل واحد ضمن 1000 شكوى استعمل 12 استدعاء تجهيز SQL بدل المرور باستعلام مستقل على كل سجل.
- استؤنف تنظيف الصفحات القديمة بعد محاكاة انقطاع الترحيل؛ الرد القديم مجهول الكاتب يتطلب صياغة ومراجعة جديدة، وتظل حالة approval القديمة قابلة للعودة الصريحة إلى المسودة.
