# إصلاحات الفحص الشامل — 1.0.0-rc.2

يدمج هذا الإصدار فرع جاهزية الإصدار مع واجهة الزجاج الحالية، ويعالج أخطاء التقرير المؤرخ 2026-11-02.

- تعديل الشكوى يرجع نتيجة متسقة مع التخزين، دون متغيرات تراجع غير معرفة.
- حفظ الحالة يسجل فروق القيم السابقة واللاحقة؛ رفض تعديل هوية الملاحظات أو تاريخها السابق، والتحقق من المسؤول الفعلي.
- التشفير عند السكون، وترحيل البيانات المحلية، وحماية النسخة الاحتياطية ومفتاح استعادتها من فرع الجاهزية.
- الفصل بين آخر محرر للرد ومعتمده، والصلاحيات المخصصة والتحقق الثنائي ومسارات الموافقات.
- ربط ملفات التسجيل بلقطة نموذج الحفظ نفسه؛ إلغاء النموذج لا ينقل اختيار ملف إلى شكوى لاحقة.
- استعادة وظائف الواجهة الحديثة، وتكامل التراجع وسلامة المستندات مع تفاصيل التدقيق المشفرة.
- الخروج للمراجع، وضوابط الشكوى المغلقة والإحالات وإعادة الفتح والأرشفة القابلة للمراجعة.
- نسخة مشفرة قبل استيراد المزامنة، ومعاينة التعارضات وفحص تغير المراجعة أثناء النسخ.
- ملف المزامنة مشفر ومصادق عليه بالكامل باستخدام AES-256-GCM ومفتاح مشتق بـscrypt من عبارة مرور النقل؛ يضم المرفقات وبياناتها الوصفية، ويعاد تشفيرها بمفتاح الجهاز المستلم.
- جميع المرفقات الواردة تفحص قبل الكتابة؛ ترفض تعارضات بايتات ملف موجود، وتتراجع الملفات الجديدة عند فشل معاملة الاستيراد.
- رفض المزامنة النصية القديمة عبر API. التصدير الآن POST مع CSRF وعبارة مرور 16–200 حرف. ترسل العبارة منفصلة عن الملف، ويعامل حاملها مصدرًا موثوقًا للبيانات.
- الحد الأقصى للمحتوى الداخلي 64MiB، وللطلب المشفر 96MiB. الأرشيف الأكبر ينقل بالنسخة الكاملة. تظل المزامنة يدوية لجهاز محلي، ولا تقدم خادم إنترنت مشتركًا.
- تحديث كلمات المرور لتجنب قص bcrypt بعد 72 بايتًا، ودعم التحقق والترحيل للحسابات القديمة.
- PDF بخط عربي محلي وتعدد صفحات؛ مهلة المتابعة وتوقيت دمشق وقواعد التأخر موحدة.
- تصدير CSV عبر الخادم لكل العرض والمحدد، مع تحييد الصيغ وتسجيل التصدير.
- حفظ الإعدادات والإجراءات الجماعية ينتظر تأكيد الخادم، وتحسين تجدد حالة إجراءات الصفوف.
- إزالة 17 ملف واجهة قديمًا، واعتماد قائمة تغليف محددة، وتحديث الاعتمادات وCI واختبار فتح EXE المبني.

## التحقق

نجح التشغيل الكامل للاختبارات: 201 اختبار، دون فشل أو إلغاء أو تخطٍ. تشمل الاختبارات الجديدة التعديل والتدقيق المشفر وانتحال الملاحظات وعبث ملف المزامنة وانتقال مرفق نموذج ملغى. اختبار جهازين محليين يثبت نقل بايتات مرفق داخل الحزمة المشفرة، واستيرادها وتنزيلها من الجهاز الآخر. فحص المصدر وتجميع الواجهة ناجح. فحص قفل جميع الاعتمادات: صفر تنبيهات في وقت التنفيذ.

## التشغيل والتحديث

التحديث المعتمد هو استبدال EXE من بناء موثوق بعد نسخة كاملة مجربة، مع إبقاء مجلد userData. ملفات البرنامج ضمن المزامنة الموقعة تبقى للمراجعة ولا تطبق تلقائيًا. لم ينفذ اختبار Windows يدوي أو قياس حمل إنتاجي أو فحص بصري لكل الدقات في هذه البيئة. لا يثبت هذا التحديث تحقق RTO ميدانيًا أو وجود نسخة خارج الجهاز. يجب ضبط موقع النسخ الخارجي وحفظ الأسرار وإجراء تمرين استعادة على الجهاز الفعلي.

حماية main بقواعد مراجعة وتوقيع EXE بمفتاح الجهة وتثبيت مرجع تدقيق خارجي تتطلب إعدادات ومستندات ثقة خارج مصدر التطبيق، ولم يغيرها هذا الالتزام. لا تعد نتيجة الاختبارات شهادة إغلاق لهذه المتطلبات التشغيلية.
