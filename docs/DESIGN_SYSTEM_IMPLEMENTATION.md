- تحميل ملف النظام بعد `ui-compat.css`؛ يحتوي الأخير تنسيقات سير العمل السابقة داخل طبقة `legacy` منخفضة الأولوية، مع إزالة `!important` منها. ملفات التنسيق الستة السابقة محفوظة للمقارنة ولا تُحمّل من الصفحة. أي تطوير بصري جديد يُضاف إلى `ui-system.css`، ولا تُعدّل النسخ السابقة لتجنب إنشاء مصدرين نشطين للتنسيق. إزالة تنسيقات التوافق غير المستخدمة تدريجيًا تتطلب قبولًا بصريًا لكل شاشة.
- الشريط الجانبي متجاوب مع خلفية إغلاق؛ دعم الوضع الداكن وتقليل الحركة والشفافية، ورابط لتجاوز التنقل.
- خيار البقاء مسجّلًا 30 يومًا بتفعيل صريح؛ المدة الافتراضية 30 دقيقة. بيانات الاعتماد لا تُحفظ في localStorage؛ تُستخدم الجلسة الخادمية القائمة وكوكي HttpOnly وSameSite=Strict.
- رسائل خطأ داخل نموذج الدخول، حالة انتظار، منع تكرار الإرسال، إعادة التركيز ومسح حقل كلمة المرور بعد الدخول.
- إصلاح إغلاق الدالة الرئيسية الناقص في تجميع الواجهة؛ كانت نسخة main تفشل في تحليل JavaScript.
- استعادة توصيل أزرار التنقل وCSV، وإتاحة قفل الأزرار داخل نطاق التجميع، وتأجيل تحميل السكريبتات حتى اكتمال عناصر الدخول.
- إزالة تحميل الحالة غير المشروط قبل التحقق من هوية المستخدم؛ تحديث قائمة ملفات الخدمة المحلية ونسخة الذاكرة المؤقتة، وإضافة الملفات إلى قائمة تقديم الخادم. بيانات API والمرفقات تبقى خارج التخزين المؤقت.
