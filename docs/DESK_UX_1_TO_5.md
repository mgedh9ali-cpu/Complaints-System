## 2) ملف الشكوى كشاشة عمل

- شريط **مهلتين** (أول رد + الحل) في أعلى الملف.
- قسم **قصة السجل** يجمع التسجيل والملاحظات والإحالات والرد وآخر أحداث الخط الزمني.
- الخطوة التالية المقترحة (`next-step.js`) تبقى كما هي.

## 3) طوابير العمل

- شريط طوابير تحت اختصارات مساحة العمل: متأخرة، مهددة، تأخر أول رد، بيانات ناقصة، إحالات، اعتمادات، وضع استقبال.
- طابوران جديدان في السجل ولوحة العمل:
  - `at-risk`: ≥ 75٪ من مهلة الحل ولم تُتجاوز بعد
  - `first-response-late`: لم يُسجَّل رد/إحالة/ملاحظة خلال مهلة أول رد

## 4) مهلة ظاهرة وإغلاق منظم

- مهلة أول رد الافتراضية: 48 ساعة (`settings.firstResponseHours`)
- مهلة الحل: `settings.slaDays` (افتراضي 7)
- عند اختيار إغلاق أو إلغاء تظهر حقول إلزامية:
  - السبب الجذري
  - الإجراء المتخذ
  - قناة إبلاغ المواطن
- تُدمج في نص سبب تغيير الحالة قبل الإرسال للخادم (متوافق مع API الحالي دون ترحيل مخطط).

## 5) تسجيل أذكى + وضع استقبال

- كشف التكرار بالهاتف (موجود) + اقتراح بالاسم والتصنيف.
- زر **وضع استقبال**: يفتح نموذج التسجيل مع تنبيه واضح ويبقي التفاصيل الإضافية مطوية؛ بعد الحفظ يظهر الرقم المرجعي كالمعتاد.

## ملف جديد

- `ui/features/desk-ux.js` — يُحمَّل عبر `lib/ui-bundle.js`

## اختبار يدوي مقترح

1. افتح لوحة العمل → تظهر مهام «مهددة» / «تأخر أول رد» عند وجود بيانات.
2. افتح سجلًا → شريط المهل + قصة السجل.
3. غيّر الحالة إلى مغلق دون سبب جذري → يُرفض.
4. سجّل شكوى برقم هاتف مكرر → تلميح التكرار.
5. اضغط وضع استقبال → بانر الاستقبال.
