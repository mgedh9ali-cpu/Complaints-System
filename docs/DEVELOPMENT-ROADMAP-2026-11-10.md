# خطة تطوير نظام الاستفسارات والشكاوى — 2026-11-10

هذه الخطة تسجل الاقتراحات المعتمدة وحالة تنفيذها. وجود بند هنا لا يعني اكتمال تنفيذه أو اجتياز اختباره على Windows. يبقى النشر الرسمي مرتبطًا بنتائج الاختبار الفعلي.

## التنفيذ في هذه الدفعة

- خيار كثافة عرض مريح أو مضغوط في إعدادات العرض؛ محفوظ على الجهاز.
- خيار حركة خفيفة أو متوقفة؛ يوقف الحركات والانتقالات والعدادات المتحركة ويحترم تفضيلات النظام.
- زر «حفظ وإضافة جديد» يستخدم نفس مسار الحفظ والمصادقة ثم يفتح نموذجًا جديدًا بعد نجاح الحفظ.
- منع حفظ النموذج بالتوازي عبر أزرار الحفظ المختلفة لتجنب إنشاء سجلين من ضغطات متزامنة.
- إزالة ملف مختار من معاينة مرفقات الإدخال قبل الحفظ، مع الاحتفاظ بالبقية عند التنقل بين الخطوات.
- أهداف لمس أكبر للأزرار على أجهزة الإدخال اللمسية.

## موجود ويحتاج استمرار التحقق

| المجال | الموجود | التحقق المطلوب |
|---|---|---|
| التصميم | طبقة ui-tokens.css وخط ثمانية وقوالب عرض وإدخال محسنة | تدقيق بصري على الوضعين والشاشات الصغيرة وتباين النصوص |
| الحركة | دخول صفوف محدود وحالة SLA ثابتة واحترام تقليل الحركة | قياس التمرير على جهاز ضعيف؛ منع إعادة النبض اللانهائي |
| الحفظ | مسار خادمي وتغذية راجعة عند الحفظ | انقطاع الاتصال أثناء الحفظ وبعد نجاح POST وقبل تحديث العرض |
| الفلاتر | فلاتر محفوظة محليًا | ربط تفضيلات كل حساب ومنع مشاركة أسماء حساسة بين الحسابات |
| الصلاحيات | أذونات خادمية واختبارات رفض واعتماد من مستخدم مستقل | مصفوفة كل إجراء وكل دور مع صلاحيات مخصصة |
| البيانات | حماية ملفات ومرفقات وسجل تدقيق ونسخ احتياطي | استعادة كاملة بمرفقات في بيئة مستقلة ومقارنة النتائج |
| التشغيل | startup-timings.json وقياسات مراحل بدء التشغيل | قياسات حقيقية للنسخة المثبتة والمحمولة على Windows |

## الأعمال التالية ومعايير قبولها

| الأولوية | الاقتراح | معيار القبول |
|---|---|---|
| عالية | تشخيص التشغيل البطيء | مقارنة بدء تشغيل بارد ودافئ وتحديد المرحلة الأبطأ من القياسات قبل تعديلها |
| عالية | اختبار استعادة دوري | استرجاع قاعدة ومرفقات وحسابات اصطناعية في مجلد مستقل والتحقق من سجل التدقيق |
| عالية | نسخة مشفرة خارج جهاز العمل | اختيار وجهة خارجية من المستخدم، واختبار الكتابة والاستعادة وفشل الوجهة دون فقد النسخة المحلية |
| عالية | قفل عند الخمول مع تنبيه | وقت قابل للضبط، حفظ آمن للمسودة، وإعادة دخول خادمية قبل استئناف العمليات |
| عالية | مراجعة حماية المسودات | فحص localStorage/sessionStorage، وتحديد طريقة تخزين تحمي محتوى المواطنين وتفصل الحسابات |
| عالية | إعادة التحقق للعمليات الحساسة | إثبات حديث لكلمة المرور قبل الاستعادة وتغيير الصلاحيات والمفاتيح، مفروض من الخادم |
| عالية | مراجعة التحديثات | التحقق من مصدر الحزمة والتوقيع والهوية والإصدار، واختبار الفشل والرجوع وحفظ البيانات |
| متوسطة | حالة حفظ المسودة ووقتها | وقت آخر حفظ حقيقي ورسالة فشل واضحة؛ عدم إظهار نجاح عند امتلاء التخزين |
| متوسطة | تخصيص أعمدة السجل | إظهار وترتيب الأعمدة وحفظ إعداد الحساب مع بقاء رقم السجل وإجراءات الوصول الأساسية |
| متوسطة | ملخص الملف | الحالة والمسؤول وآخر إجراء والموعد القادم؛ استخراجها من البيانات الفعلية |
| متوسطة | تصفية سجل الأحداث | نوع الإجراء والمستخدم والتاريخ دون تغيير ترتيب الدليل أو إمكانية تعديل الأحداث |
| متوسطة | تقارير إضافية | مدة المعالجة وإعادة الفتح وأسباب التأخر مع تعريف واضح للمؤشرات والفترة |
| متوسطة | الانتقال من الرسم للسجلات | فتح قائمة تطابق أرقام الرسم وفلاتره مع إمكانية العودة للتقرير |
| متوسطة | شاشة حالة النظام | الإصدار وآخر نسخة ناجحة ومساحة التخزين دون عرض أسرار أو تفاصيل مواطنين |
| متوسطة | اختبار 10 آلاف سجل | بيانات اصطناعية فقط؛ قياس البحث والفرز والتقارير قبل وبعد أي تحسين |
| متوسطة | توحيد CSS والخط | حصر الملفات الفعالة قبل حذف القديم، وتوحيد الأحجام والأوزان والأزرار والأيقونات تدريجيًا |
| متوسطة | مراجعة الوضع الليلي | القوائم والنوافذ والحقول والشارات وحالات التركيز والخطأ، لا الخلفية وحدها |

## قبول إصدار Windows

اختبار فتح التطبيق وتسجيل الدخول وإنشاء شكوى واستفسار وإضافة وإزالة مرفق وتعديل سجل وتغيير حالة واعتماد رد بواسطة مستخدم مستقل، ثم PDF وWord ونسخ احتياطي واستعادة وتحديث فوق الإصدار السابق. نجاح الاختبارات الآلية وحده لا يثبت اجتياز هذه التجربة.

لا تتطلب هذه الخطة إدخال بيانات حقيقية أو شراء خدمات. وجهة النسخة الخارجية تبقى غير محددة حتى يختارها المستخدم.


## تفاصيل المقترحات البصرية والوظيفية للمطابقة

هذه التفاصيل توسّع البنود العامة أعلاه، وليست إعلانًا باكتمال تنفيذها. تعتمد حالة التنفيذ على قسمي «التنفيذ في هذه الدفعة» و«الأعمال التالية».

| المجال | التفاصيل المقترحة |
|---|---|
| الهوية البصرية | أخضر رسمي أساسي، خلفيات هادئة، ذهبي محدود للعناصر المهمة، وأحمر للأخطاء والإجراءات الخطرة |
| اتساق الصفحات | توحيد المسافات والعناوين والحقول والبطاقات في جميع الصفحات |
| الخط | الاحتفاظ بثمانية؛ اختبار نصوص 15–16، جداول 14–15، وعناوين 22–28 بكسل؛ عادي للنص ومتوسط للعناوين الصغيرة وعريض للعناوين المهمة والأزرار |
| ترتيب الأزرار | زر أساسي واضح لكل منطقة، مثل حفظ الشكوى أو تحديث الحالة؛ الإجراءات الثانوية في المزيد |
| حالة الأزرار | جارٍ الحفظ أثناء الطلب، منع الإرسال المتكرر، ونجاح بعد تأكيد الخادم فقط |
| الأيقونات | مجموعة متناسقة واحدة، نص بجانب الإجراءات المهمة وتلميحات للأزرار ذات الأيقونة وحدها |
| كثافة العرض | مريح ومضغوط، مع حفظ الاختيار؛ نُفذ في هذه الدفعة |
| الوضع الليلي | مراجعة الخلفيات والحقول والقوائم والنوافذ والشارات وحالات الخطأ والتركيز |
| حركة الزر | ارتفاع عند المرور 1–2 بكسل وضغط خفيف قصير |
| حركة النافذة | ظهور تدريجي نحو 150–200 مللي ثانية كنقطة بداية للاختبار |
| حركة الجدول | دخول أول الصفوف الظاهرة فقط وتغيير الخلفية عند المرور |
| نجاح الحفظ | علامة نجاح تظهر مرة واحدة |
| مؤشرات الحالة | لون ونص ثابتان للتأخر والأولوية دون نبض مستمر |
| التحكم بالحركة | خفيفة أو متوقفة مع احترام تقليل الحركة في الجهاز؛ نُفذ في هذه الدفعة |
| سرعة الإدخال | حفظ وإضافة جديد للمكالمات المتتالية؛ نُفذ في هذه الدفعة |
| المسودة | حالة حفظ على هذا الجهاز ووقت آخر حفظ حقيقي، مع بيان الفشل |
| المرفقات | اسم وحجم قبل الحفظ وإزالة الملف المختار بالخطأ؛ نُفذت الإزالة في هذه الدفعة |
| نوع السجل | حقول مناسبة لكل نوع ونموذج استفسار أخف من الشكوى |
| ملخص الملف | الحالة والمسؤول وآخر إجراء والموعد القادم |
| سجل الإجراءات | تصفية الملاحظات والإحالات والردود وتغييرات الحالة |
| أعمدة السجل | إظهار الأعمدة وترتيبها وحفظ الاختيار للمستخدم |
| الفلاتر المحفوظة | حفظ الاستعلامات المتكررة مثل شكاوى دمشق المتأخرة واستفسارات اليوم؛ مراجعة فصلها بين الحسابات |
| الصلاحيات | اختبار كل إجراء في الخادم لكل دور، بما فيه تجاوز واجهة المستخدم |
| الخمول | قفل تلقائي قابل للضبط وتنبيه قبل القفل وحماية المسودة |
| حماية المسودات | مراجعة تخزين بيانات المواطنين وفصل الحسابات |
| العمليات الحساسة | إعادة التحقق قبل الاستعادة وتغيير الصلاحيات والمفاتيح |
| النسخ الاحتياطي | اختبار استعادة دوري، ونسخة مشفرة خارج جهاز العمل بعد اختيار الوجهة |
| التحديث | التحقق من المصدر وسلامة الحزمة والتوقيع ومسار الرجوع عند الفشل |
| أداء التشغيل | قراءة القياسات الفعلية على جهاز المستخدم وتحديد المرحلة الأبطأ |
| اختبار الحجم | بيانات وهمية حتى 10 آلاف سجل وقياس البحث والفرز والتقارير |
| نظافة التنسيق | توحيد CSS تدريجيًا وإزالة القواعد القديمة المتعارضة بعد التحقق من استخدامها |
| التقارير | مدة المعالجة والسجلات المعاد فتحها وأسباب التأخر؛ الضغط على الرسم يفتح السجلات المطابقة |
| حالة النظام | الإصدار وآخر نسخة احتياطية ناجحة ومساحة التخزين |
| اختبار الإصدار | تجربة Windows فعلية تشمل الفتح والدخول والإدخال والمرفقات والتصدير والنسخ والاستعادة والتحديث |
