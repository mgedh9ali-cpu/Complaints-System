# مصفوفة الميزات — الوضع الحالي مقابل المقترح

مرجع سريع لما ورد في مراجعة أنظمة الشكاوى المفتوحة، مقابل **Complaints-System 0.7.2**.

## ميزات جوهرية

| الميزة | الحالة | ملاحظات |
|--------|--------|----------|
| مصادقة + أدوار RBAC | ✅ موجود | `admin` / `staff` / `reviewer` + صلاحيات دقيقة |
| دورة حياة الشكوى | ✅ موجود | `new` → `in_progress` → `awaiting_*` → `closed` / `cancelled` مع سبب إلزامي للنهائي |
| لوحة متابعة | ✅ موجود | أعداد وإحصاءات محلية |
| نموذج شكوى + تحقق | ✅ موجود | فئة، أولوية، ملخص، تفاصيل… |
| إشعارات بريد إلكتروني | ❌ غير موجود | النظام offline-first؛ الإشعارات حالياً داخل التطبيق / متصفح |

## ميزات متقدمة

| الميزة | الحالة | ملاحظات |
|--------|--------|----------|
| تصدير PDF لشكوى | ❌ مخطّط | يوجد CSV/Excel للتقارير |
| تتبع برقم مرجعي بدون دخول | ✅ جزئي | `GET /api/public/track/:id` — حقول غير حسّاسة فقط |
| لوحة مواطن (مقدّم الشكوى) | ❌ غير موجود | النظام موجّه لموظفي الشعبة وليس بوابة مواطن كاملة |
| تقييم بعد الإغلاق | 🔶 حقل جاهز | `survey` على كائن الشكوى؛ واجهة التقييم تحتاج استكمالاً |
| تصدير CSV/Excel | ✅ موجود | مع فلترة وصلاحيات |
| تعدد لغات AR/EN | 🔶 عربي أساسي | الواجهة عربية RTL؛ لا يوجد i18n إنجليزي كامل |
