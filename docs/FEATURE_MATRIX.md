# مطابقة المتطلبات — مرشح 1.0.0-rc.1

| المتطلب | التنفيذ في المصدر | حد التحقق أو المتبقي |
|---|---|---|
| حسابات خاصة ينشئها المدير | API محلي ومدير وموظف ومراجع؛ منع التسجيل العام | ليست خدمة حسابات عبر الإنترنت |
| صلاحيات فردية للمساعدين | تجاوزات خادمية لكل مستخدم، وإبطال الجلسات عند التغيير | ضبط الصلاحيات الفعلية مسؤولية مدير التشغيل |
| الاطلاع على التفاصيل لكل المساعدين | متاح وفق صلاحية القراءة | لا توجد بوابة عامة للمواطنين |
| تحقق ثنائي | TOTP محلي اختياري ورموز استرداد لمرة واحدة | يلزم تفعيله واعتماد سياسة المؤسسة |
| رقم رسمي عند أول حفظ | SY-YYYY-NNNNNN متسلسل؛ يدعم غير المكتمل | السنة بتوقيت دمشق |
| دورة الحالة وأسباب القرارات | خادم يضبط الانتقالات والإغلاق والإلغاء وإعادة الفتح | الإلغاء بعد إجراء رسمي يحتاج موافقة أخرى |
| الرد الرسمي | صياغة ومراجعة واعتماد وتوثيق إرسال منفصل | المؤلف وآخر محرر لا يعتمدان؛ الإرسال هنا توثيق يدوي |
| مسؤول ومساعدون | إسناد لحسابات معالجة نشطة، ومساعدون مشاركون | لا توجد أسماء موظفين تجريبية في قوائم الإسناد النشطة |
| الإحالات | حفظ الإحالة والحالة والتدقيق معًا، وتسجيل رد الجهة | لا إرسال إلى جهة خارجية تلقائيًا |
| الإغلاق بعد الإحالات | يمنع الإغلاق دون ردود، أو يسمح باستثناء موثق لمخول | سياسة الاستثناء تعتمدها المؤسسة |
| حذف بموافقة مدير | طلب ومراجع آخر، ورفض الاعتماد الذاتي أو القديم | الشكوى تُؤرشف؛ المرفق ينقل لأرشيف خاص، دون إتلاف نهائي |
| التكرار | اقتراح وربط مع الأصل بعد موافقة؛ منع الدورات | قرار بشري؛ التشابه في الواجهة تنبيه فقط |
| الاستكمال | حفظ ناقص وتحرير البيانات وقائمة وتذكير قابل للإيقاف | اسم المشتكي والهاتف لا يفرضان كهوية رسمية |
| المهل والتصعيد | خدمة خادمية أثناء التشغيل، بعد اعتماد SLA | ليس خدمة تعمل والجهاز مطفأ |
| سجل التدقيق | أحداث ضمن المعاملات وقيم قبل/بعد وسلسلة تحقق | رأس السلسلة محلي؛ يلزم مرجع مستقل خارج الجهاز لمقاومة مسؤول الجهاز |
| حماية المحتوى والمرفقات | AES-GCM وسياق مرتبط بالسجل، وقراءة مصرح بها ومدققة | تشفير القرص وحماية ملف المفاتيح وفحص البرمجيات الضارة يلزم اعتمادها ميدانيًا |
| النسخ | كامل مشفر، تحقق باستخراج، كل 15 دقيقة، يومي 30 يومًا | القرص نفسه لا يغطي فقد الجهاز؛ RPO/RTO يحتاجان قياسًا ميدانيًا |
| الاستعادة | استخراج إلى مجلد فارغ واختبار نقل قاعدة ومرفقات ومفاتيح | لا واجهة استعادة بنقرة واحدة؛ يلزم قبول على Windows |
| المزامنة | معاينة فرق وتأكيد ونسخة أمان إلزامية قبل الاستبدال | ملفات نقل يدوي؛ ليست قاعدة مشتركة ولا مزامنة آنية |
| قنوات الورود | الهاتف، واتساب، تلغرام، أخرى، بتسجيل يدوي | التكامل الرسمي مع القنوات مؤجل |
| التقارير | CSV وExcel وPDF عربي متعدد الصفحات | اختبارات مصدر وإخراج؛ قبول Windows والطباعة الفعلية ما يزالان مطلوبين |
| الواجهة | RTL، الهاتف، الوضع الداكن، صفحات مستقلة، سجل بصفحات 50 صفًا | الاختبارات الحالية تحاكي DOM؛ لم يصل المتصفح السحابي للخادم المحلي |
| توسع البيانات | تجنب إعادة كتابة الصفوف غير المتغيرة، وصفحات في العرض | API الحالة ما يزال يحمل لقطة كاملة بحد طلب 16MiB؛ لم يتحول إلى قاعدة مركزية بترقيم خادمي كامل |
| Windows EXE واحد | إعداد بناء محمول وASAR وبيانات خارج EXE وقائمة ملفات صريحة وفحص تشغيل آلي معزول | أُنتج EXE ببناء متقاطع؛ لم يُشغّل على Windows، وغير موقع رقميًا لغياب شهادة الجهة |
| تعدد مواقع الموظفين | غير منفذ في هذا البناء المحلي | يحتاج بنية خادمية معتمدة واتصالًا آمنًا وقاعدة مشتركة |
| سياسات رسمية | لا إتلاف تلقائي لسجلات المواطنين، والرقم الوطني غير مفروض | البلاغ المجهول والاحتفاظ الرسمي وإجراءات الإتلاف تحتاج قرار الجهة |
| الذكاء الاصطناعي | مؤجل | وفق القرار السابق |
