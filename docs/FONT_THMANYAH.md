# Thmanyah Sans داخل التطبيق

يعتمد التطبيق ملفات WOFF2 الأصلية المرفقة داخل assets/fonts/thmanyah للأوزان Light (300)، Regular (400)، Medium (500)، Bold (700)، Black (900). لا يلزم تثبيت الخط على Windows أو الاتصال بخادم خطوط خارجي.

تعرّف thmanyah-fonts.css الأوزان باستخدام روابط نسبية تعمل في واجهة الخادم المحلي وشاشة بدء Electron. يتيح server.js الملفات الخمسة فقط ضمن قائمة الملفات العامة، وتضمّنها إعدادات electron-builder في Setup وPortable. يبقى Cairo وNoto Sans Arabic بديلين، وتستخدم ملفات PDF المولدة على الخادم Noto Sans Arabic.

## التحقق

شغّل npm run check وnpm test ثم npm run dist:win. يفحص tests/font-local.test.cjs ترويسات WOFF2 وأحجام الملفات وربط الواجهة وشاشة البداية. يفحص tests/cleanup-regressions.test.cjs فك الملفات وتغطية الأحرف العربية. أثناء بناء Windows يفحص desktop/verify-fonts.js تحميل الأوزان الخمسة واستخدام ملف ثمانية فعليًا لرسم عنوان الدخول عبر Chromium؛ فشل ذلك يمنع النشر.

## المصدر والحقوق

المصدر هو حزمة Thmanyah-Font-Family.zip التي قدمها مالك المستودع. أُضيفت الملفات الأصلية دون تعديل بناءً على تصريحه بأنه صاحب الحقوق وطلبه الصريح نشرها في المستودع العام بتاريخ 2026-11-09. حُفظ ملف LICENSE.pdf المرفق كما هو. هذه الملاحظة تسجل تفويض مالك المستودع ولا تعد إثباتًا مستقلًا لإلغاء ترخيص ثمانية المنشور، ولا تمنح الآخرين ترخيصًا جديدًا. راجع https://font.thmanyah.com/licenses لأي استخدام مستقل.

لم يُعد كتابة تاريخ Git أو استرجاع أجزاء Base64 القديمة التالفة.
