# تطبيق خط ثمانية على واجهة نظام الشكاوى

الخط الأساسي المحدد في CSS هو **Thmanyah Sans** (Regular 400، Medium 500، Bold 700)، مع خط **Tahoma / Segoe UI** بديلاً عند عدم تثبيت خط ثمانية على جهاز التشغيل. يطبّق المتصفح الخط على النصوص والأزرار والحقول والجداول والواجهة كاملة.

## تفعيل الخط على جهاز Windows

1. نزّل النسخة الأصلية بصيغة OTF من [صفحة ثمانية الرسمية](https://font.thmanyah.com/) بالبريد الإلكتروني الخاص بك.
2. افتح الحزمة السليمة، وثبّت ملفات **Thmanyah Sans Regular وMedium وBold** على Windows (انقر بزر الفأرة الأيمن واختَر «تثبيت لجميع المستخدمين» إذا كانت الصلاحيات تسمح، أو «تثبيت» لحساب Windows الحالي).
3. أغلق تطبيق نظام الشكاوى وافتَحه مجددًا. ستُستخدم عائلة Thmanyah Sans تلقائيًا في النصوص والحقول والأزرار. لا تحتاج إلى تعديل CSS أو تحميل خطوط من الإنترنت.
4. جرّب قراءة نص عربي طويل ورقم شكوى في القوائم والجداول. إذا لم يظهر الخط، فتحقق من ظهوره في إعدادات الخطوط في Windows ومن اسم العائلة المثبّت.

## ملاحظة الترخيص

[ترخيص ثمانية الرسمي](https://font.thmanyah.com/licenses) يسمح باستخدام الخط في التطبيقات ولكنه يمنع إتاحة ملفات الخط مستقلة للتحميل أو إعادة نشرها عبر GitHub أو خادم الويب. لذلك **لا توضع ملفات OTF أو WOFF2 أو نسخ Base64 للخط في هذا المستودع**، ولا يتولى التطبيق تنزيل الخط أو توزيعه. هذا الإصدار يعتمد على خط مثبّت محليًا.

## حالة الملف المرفق

ملف **Thmanyah-Font-Family.zip** المرفوع خلال إعداد المشروع ظهر كأرشيف غير مكتمل: لم توجد فهرسة ZIP النهائية ولا ملفات خط سليمة قابلة للاستخراج. لا نعتبره مصدرًا صالحًا لتضمين الخط في البناء. يمكن تثبيت النسخة الرسمية المستخرجة سليمًا على جهاز Windows دون تغيير المستودع.

للاستفادة من وزن آخر مستقبلاً، ثبّت وزن OTF الموافق له وفق شروط ثمانية. لا يحتاج تطبيق الواجهة إلى خدمة خطوط خارجية.
