# خطة التعديلات الكبيرة — الحالة

| # | البند من المواصفات | الحالة في المشروع |
|---|---------------------|-------------------|
| 1 | فصل مجلد البرنامج عن بيانات المستخدم | **منفّذ** في Electron (`userData` + `data/complaints.sqlite`) |
| 2 | علامة `data-root.json` | **منفّذ** عند فتح القاعدة |
| 3 | ترقيات بنية متسلسلة `schema_migrations` | **منفّذ** إطار التشغيل + هجرات أولية |
| 4 | نقل بيانات إصدار سابق (معالج كامل) | **جزئي** — استعادة `.csb` عبر Electron تغطي النقل الآمن |
| 5 | سرعة التشغيل / تحميل تدريجي | **جزئي** — صفحات عند الطلب + ترقيم سجل 50 + بدون blur على الجداول |
| 6 | بحث بنوع التاريخ والفترة | **منفّذ** (تسجيل / تحديث / موعد / إحالة / إغلاق) |
| 7 | إحالات كسجلات مستقلة مع ردود | **موجود** داخل payload JSON لكل شكوى + صفحة إحالات |
| 8 | غلاف طباعة شكوى | **منفّذ** `print-complaint-cover` |
| 9 | إيصال PDF ورد معتمد | **موجود مسبقاً** |
| 10 | شاشة إدخال عمودين | **موجود** شبكة حقول + تحسينات CSS |
| 11 | جداول SQL منفصلة referrals/responses | **مؤجّل** — يتطلب إعادة تصميم التخزين المشفر بالكامل |

لا يُعاد بناء نموذج JSON المشفر إلى جداول علاقية في هذه الدفعة لتجنب كسر البيانات الحية.
