# إكمال الإصدار 1.0.0-rc.3

أُصلحت أسباب فشل Windows في تنظيف ملفات الاختبار المفتوحة وتوافق أنماط المسارات، مع إبقاء الاختبارات وإضافة مهلة واضحة لها.

تتضمن هذه الدفعة:

- حقلًا مخفيًا لعبارة مرور المزامنة، ومعالجة اختيار الملف بعد التنقل وإعادة رسم الإعدادات.
- قبول المزامنة الكبيرة ضمن حد 96MiB بعد التحقق من الحساب والصلاحية وCSRF، مع بقاء الحد العام الأصغر.
- ربط تأكيد الاستيراد برقم مراجعة المعاينة، والتحقق من المرفقات وإعادة الاستيراد قبل النسخ أو تجهيز الملفات.
- منع تعذر مجلد النسخ الخارجي من تعطيل بدء التطبيق، وإعادة المحاولة وإظهار الفشل.
- قائمة Windows لاختيار مجلد النسخ وحفظ مفتاح الاستعادة والاستعادة إلى مجلد مستقل دون حذف البيانات الحالية.
- نشر EXE وبصمة تحقق وبيانات المصدر تلقائيًا بعد نجاح بناء Windows واختبار تشغيله، وإثبات منشأ البناء عبر GitHub.

التحقق المحلي: 208 اختبارات ناجحة، وفحص 81 ملف JavaScript و15 مصدر واجهة. يشمل اختبار المزامنة الحقيقي حزمة تتجاوز 16MiB مع مرفقات بين نسختين مستقلتين. نتيجة Windows النهائية مرجعها Actions للالتزام المنشور؛ النجاح المحلي ليس بديلًا عنها.

لا تتضمن التغييرات شهادة توقيع Windows باسم جهة، ولا يمكن اختيار وسيط نسخ خارج جهاز المستخدم من بيئة التطوير. اختيار الوسيط وحفظ مفتاحه متاحان الآن من الواجهة عند الاستخدام. قبول الشاشة والطباعة والاستعادة على الجهاز الفعلي هو اختبار المستخدم الأخير.
