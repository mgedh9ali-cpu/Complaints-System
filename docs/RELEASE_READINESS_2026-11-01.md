## ما يمنع اعتماد إطلاق نهائي

1. **Windows:** أُنتج EXE ببناء متقاطع على Linux، وما زال تشغيله على Windows غير مثبت. يلزم فتحه على جهاز نظيف، تجربة RTL والتكبير والطباعة ورفع الملفات والنسخ والتحديث مع حفظ البيانات. اختبار وضع Node داخل Electron لا يتحقق من نافذة سطح المكتب.
2. **الاستعادة والتعافي:** تمرين فعلي على جهاز آخر ووسيط خارج الجهاز وقياس RPO/RTO. الجدولة كل 15 دقيقة ليست إثباتًا لتحقيق RPO=15 دقيقة وRTO=8 ساعات عمل. لا توجد واجهة استعادة بنقرة واحدة.
3. **حماية الجهاز والمفاتيح:** التشفير هنا للمحتوى، وليس لكامل SQLite أو القرص؛ تبقى الأرقام وأسماء الحسابات وبعض الفهارس والتواريخ مكشوفة. من يتحكم بحساب نظام التشغيل يستطيع الوصول إلى ملف المفاتيح. يلزم تشفير القرص وأذونات ونسخة مفاتيح مستقلة معتمدة.
4. **فحص الملفات:** التحقق من النوع وMIME والتوقيع ليس مضاد برمجيات ضارة؛ الربط بوسيلة مؤسسية لم يُنفذ.
5. **بنية الموظفين:** هذا خادم loopback محلي. النقل بملفات مزامنة استبدال يدوي مع كشف تعارض، وليس قاعدة مشتركة أو مزامنة آنية. إصدار الأرقام من قواعد مستقلة قد يصطدم؛ يلزم مصدر محلي واحد للأرقام أو خادم مركزي معتمد قبل استخدام عدة مواقع.
6. **السياسات:** اعتماد SLA، أدوار الموظفين، تفعيل TOTP، البلاغات المجهولة، الرقم الوطني، مدد الاحتفاظ وإجراءات الإتلاف. لم يُفرض قرار قانوني أو مؤسسي غير مزود في المتطلبات.
**أُغلق بند الاعتماديات في 2026-11-02:** صفر تنبيهات أمنية وصفر حزم مهجورة في التثبيت النظيف. يبقى هذا حكمًا على الإصدارات المثبتة وبيانات التنبيه وقت الفحص، ويعاد الفحص عند كل بناء.

التكامل المباشر مع واتساب وتلغرام والذكاء الاصطناعي لم يُنفذ؛ القنوات تسجل يدويًا والذكاء الاصطناعي مؤجل وفق النطاق السابق.

## إعادة التحقق

```bash
npm ci --ignore-scripts
npm rebuild better-sqlite3
npm run check
npm test
npm ls --all
npm audit --audit-level=low
```

بناء Windows: `npm ci` ثم `npm run dist:win` على بيئة Windows المدعومة. النتيجة المتوقعة `dist-desktop/complaints-system-1.0.0-rc.1-portable.exe`. لا تنشر نسخة ببيانات المواطنين قبل إغلاق بوابات القبول المذكورة أعلاه.

## إصلاح التنبيهات في تحديث 2026-11-02

الحالة الأمنية: **fixed لتنبيهات الاعتماديات المحددة**. كان المسار `ExcelJS → archiver/readdir-glob` و`Electron Builder → minimatch/glob` يحمل نسخ مطابقة قديمة. لا يحوّل التطبيق نص الشكوى إلى نمط glob؛ لم يثبت استغلال HTTP في المشروع، لكن إصدارات الاعتماديات كانت متأثرة بنطاق التنبيه الرسمي.

- نُقلت المطابقة إلى `minimatch@11.0.2` و`11.0.3`، واجتياز الملفات إلى `glob@14.0.3` الرسميين. لا توجد نسخة أقدم في ملف القفل أو الشجرة المثبتة.
- محولا CommonJS/callback يحافظان على الاستدعاءات الفعلية القديمة دون نسخ خوارزمية المطابقة أو تعديلها. بقيت الحزم الرسمية مرئية لفحص الأمان. أضيفت معالجة فواصل مسارات Windows والتحقق من CJS وESM.
- ترقية `fast-csv@5.0.7` و`unzipper@0.12.5` و`global-agent@4.1.6` أزالت الحزم المهجورة، بما فيها `fstream` و`lodash.isequal` و`boolean`. تنظيف مجلدات المثبت المؤقتة يستخدم `fs.rm` الأصلي مع عقد callback وإعادة المحاولة.
- أزيلت مداخل القفل القديمة المتداخلة، ثم أثبت `npm ci` نظيف و`npm ls --all` اكتمال الشجرة دون اعتماد غير صالح. لا إخفاء تنبيهات ولا استثناء advisory ولا `audit fix --force`.
- 17 اختبارًا إضافيًا غطت أنماط تضخيم خبيثة ونمطًا بديلًا بمهلة 5 ثوانٍ، والمطابقة العادية، والمسارات العربية وWindows، وASAR وفك الملفات، ومرشحات استبعاد الأسرار، وCSV وExcel، والتنظيف، وتهيئة proxy وعزل فحص EXE. جميعها نجحت على Node وElectron ضمن المجموع 190.
- أكدت مراجعة مستقلة وجود خطأ في عزل اختبار Windows: لا يكفي تغيير `APPDATA`. أُصلح بضبط `userData/sessionData/logs/crashDumps` صراحة قبل قفل النسخة الواحدة، ورفض المجلد المشغول أو الغائب. اختبارات المتابعة نجحت؛ لم تُجر مراجعة مستقلة ثانية.
- أُصلح تحذير ASAR المعطل وبيانات المؤلف والأيقونة الافتراضية، مع اختيار مجلد عمل حقيقي خارج أرشيف التطبيق.

مراجع أصل المشكلة: [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)، [GHSA-3g3m-2fjr-6pw4](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4).

التغييرات الجديدة: `package.json` وملف القفل، `vendor/`، `desktop/main.js` و`desktop/smoke-profile.js`، `scripts/check-source.js` و`scripts/smoke-packaged.js`، `tests/dependency-compatibility.test.cjs`، إعدادات CI وأيقونات `build/` والوثائق. التحقق الخادمي من الحزمة نجح على Linux؛ لم يُعتمد تشغيل نافذة Windows أو الطباعة الفعلية أو قبول الاستعادة على جهاز المستخدم.
