# دليل إصدار Windows المحلي — 0.7.8

## ما الذي يمكن إطلاقه حالياً؟

الإصدار المقصود **تطبيق Windows محلي فقط**. يعمل الخادم وSQLite على الجهاز نفسه عبر `127.0.0.1`، ولا يدعم مشاركة قاعدة البيانات بين موظفين عبر الإنترنت. لا تستخدم بيانات مواطنين حقيقية قبل اجتياز اختبارات الحماية والنسخ والاستعادة ومراجعة الإجراءات المؤسسية.

## تنزيل نسخة Windows

1. افتح [GitHub Actions](https://github.com/mgedh9ali-cpu/Complaints-System/actions/workflows/windows-portable.yml).
2. افتح آخر تشغيل ناجح **Build Windows Portable** لالتزام `main` المطلوب؛ لا تعتمد تشغيلات قديمة أو حمراء.
3. افتح قسم **Artifacts** ونزّل `complaints-system-windows-portable` واستخرج الأرشيف؛ يجب أن يحتوي الملف `complaints-system-0.7.8-portable.exe`.
4. شغّل EXE على جهاز Windows مخصص ومحدّث، بحساب Windows محدود الصلاحيات. لا يتطلب تثبيت Node.js على جهاز تشغيل النسخة المحمولة.
5. في أول تشغيل، احفظ كلمة مرور المدير المؤقتة في مكان آمن، ثم غيّرها من النظام. امنع مشاركة الجهاز والحساب مع غير المخولين.

يجب اختبار إنشاء شكوى، تغيير حالتها، الإحالة، اعتماد رد بواسطة حساب مدير مختلف، رفع وتنزيل مرفق، تنزيل نسخة احتياطية وإعادة استخراجها، ثم إعادة فتح التطبيق للتحقق من بقاء البيانات.

## مكان البيانات

يستخدم Electron مجلد `app.getPath('userData')` في حساب Windows. يحفظ داخل `data/` قاعدة SQLite والمرفقات وملفات التدقيق. لا تضع البيانات داخل مجلد EXE ولا تمسح مجلد بيانات المستخدم عند تحديث الإصدار.

## النسخ الاحتياطي والاستعادة

زر **نسخ احتياطي** ينزّل الآن ملفاً مشفّراً بصيغة `.csb` يحتوي:
- نسخة SQLite متسقة ومفحوصة؛
- جميع ملفات المرفقات في مجلد `attachments`؛
- `audit-head.hash`، إن كان موجوداً.

تُستخدم خوارزمية AES-256-GCM مع اشتقاق مفتاح scrypt وsalt عشوائي. لا تخلط بين النسخة الجديدة وبين المسار القديم `/api/backup/database` الذي يصدّر SQLite فقط لأغراض التوافق.

**احتفظ بسر النسخ الاحتياطي خارج الجهاز بطريقة محمية**: هو `BACKUP_SECRET` إن ضبطته، وإلا `SESSION_SECRET` من ملف `.env` الموجود في مجلد `userData`. فقدان السر يعني عدم إمكان فك النسخة؛ لا ترفعه إلى GitHub أو ترسله عبر محادثة.

لاستعادة نسخة باستخدام نسخة مصدر المشروع وNode.js على جهاز صيانة موثوق:

```sh
node --env-file=.env scripts/extract-complete-backup.js "backup.csb" "empty-restore-folder"
```

يجب أن يحتوي `.env` على السر **الأصلي** الذي شُفرت به النسخة. تفك الأداة الأرشيف في مجلد فارغ وتفحص SHA-256 لكل ملف وتنفذ اختبار SQLite قبل إعلان النجاح. **لا تستبدل قاعدة البيانات الحية أثناء تشغيل التطبيق**؛ أوقف التطبيق، واحتفظ بنسخة كاملة من البيانات الحالية أولاً، ثم نفّذ نقل الملفات إلى مجلد بيانات المستخدم تحت إشراف مسؤول مخوّل. لا تنسخ `sessions` أو الأسرار من جهاز آخر.

للنسخ اليومية، احتفظ بنسخة خارج الجهاز وفق سياسة الجهة؛ واختبر الاستعادة دورياً على نسخة غير إنتاجية.

## شروط اعتماد الإطلاق

- نجاح جميع خطوات CI على الالتزام المختار (بدون استثناء `npm test`).
- نجاح Windows Portable وبناء ملف EXE.
- اختبار فتح EXE وتسجيل الدخول على Windows فعلي.
- اختبار دورة حياة شكوى ومرفقاتها واستعادتها عبر ملف `.csb`.
- إقرار صلاحيات المستخدمين ومكان الحفظ وسياسة التعامل مع بيانات المواطنين.
- **Thmanyah Sans** هو الخيار الأول في CSS، ويظهر عند تثبيت ملفات OTF الأصلية على Windows من المصدر الرسمي. راجع [تعليمات الخط](FONT_THMANYAH.md). لا تُضمّن ملفات الخط الخام في GitHub أو EXE.

نطاق الاستخدام في الإصدار الحالي: **جهاز واحد محلي**. مشاركة موظفين عبر الإنترنت تستلزم بنية خادم ومصادقة واتصال آمنين وموافقة الجهة.
