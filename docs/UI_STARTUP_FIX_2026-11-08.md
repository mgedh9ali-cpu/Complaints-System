# ترتيب الأزرار وتحسين تحميل الواجهة — 8 نوفمبر 2026

## التغييرات

- أصبحت إجراءات صف الشكوى: عرض، تعديل عند السماح، والمزيد. تجمع نافذة المزيد الطباعة وPDF وWord والنسخ وطلب الأرشفة وفق صلاحيات الحساب.
- أزيلت الإضافة القديمة التي كانت تضيف تعديلًا ومسودة وطلب أرشفة مرة ثانية إلى كل صف.
- رُتبت مرشحات السجل في شبكة متجاوبة، وفُصل عنوان الشريط العلوي عن تنسيق عناوين الصفحات. نُقل مفتاح شفافية الواجهة إلى قائمة الحساب وأزيل تكرار مفتاح المظهر.
- أصبحت تحسينات الواجهة تعمل عند عرض صفحة أو نافذة، بدل مراقبة كل تغيير في نصوص العدادات والإشعارات.
- يطلب HTML حزمة الواجهة المؤجلة مباشرة، وتُجمع مصادرها مرة واحدة لكل عملية تشغيل لنسخة سطح المكتب. تبقى قراءة المصادر حديثة أثناء التطوير.
- فُعّل Cairo المحلي المكتمل، وأوقفت محاولة إعادة بناء ملفات ثمانية عند التشغيل. مصادر ثمانية الموجودة تضم ملفات مفقودة أو غير مكتملة، وإعادة بنائها داخل أرشيف التطبيق غير قابلة للاعتماد.

## التحقق

- `npm run check:sqlite`: ناجح.
- `npm run check`: ناجح؛ 88 ملف JavaScript و32 مصدر واجهة.
- `npm test`: نجح 258 اختبارًا، دون تجاوز أو تعطيل أي اختبار.
- اختبار DOM إضافي على بيانات اصطناعية من 50 سجلًا: انخفضت أزرار الصف من 10 إلى 3. لم تعد تحديثات نص عداد تجري فحصًا كاملًا للصفحة؛ في السيناريو نفسه انخفض عدد استدعاءات البحث في المستند من 780 إلى صفر بعد 20 تحديثًا للنص. هذا قياس لمحاكاة DOM، وليس قياسًا لزمن تشغيل Windows.
- اختُبرت نافذة المزيد والصلاحيات والتصدير ومسار طلب الأرشفة، وأضيف اختبار يثبت عدم إعادة قراءة ملفات الحزمة عند إعادة تحميل سطح المكتب.
- `git diff --check`: ناجح.

## الحدود والمتابعة
