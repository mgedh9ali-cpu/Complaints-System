# تنزيل وتحديث نسخة Windows

الإصدار الحالي: **1.0.0-rc.3**، ملف Windows x64 محمول لا يحتاج تثبيت Node.js.

## التنزيل والتشغيل

افتح [صفحة الإصدارات](https://github.com/mgedh9ali-cpu/Complaints-System/releases)، ونزّل ملف `complaints-system-1.0.0-rc.3-portable.exe` من الإصدار المنشور. ينشئ أول تشغيل حساب المدير المحلي ويعرض كلمة مروره مرة واحدة؛ احفظها. قوائم النسخ والاستعادة والتحديث موجودة أعلى نافذة التطبيق.

## التحديث

1. من داخل التطبيق نزّل نسخة احتياطية كاملة، واحفظ مفتاح الاستعادة منفصلًا من قائمة **النسخ والاستعادة**.
2. افتح **التحديث والمساعدة ← تنزيل أحدث إصدار**، ونزّل EXE من المستودع نفسه.
3. أغلق التطبيق، واستبدل EXE أو شغّل الملف الأحدث. البيانات والإعدادات تبقى خارج EXE داخل `%APPDATA%\complaints-local-system`.

لا تُشغّل ملفات برنامج واردة في المزامنة تلقائيًا. حزمة المزامنة لنقل البيانات والمرفقات المشفرة بين نسخ معتمدة؛ تحديث التطبيق الكامل يتم عبر إصدار Windows المنشور.

## مصدر الحزمة والتحقق

بناء Windows يشغّل فحص المصدر، واختبارات المشروع، وتدقيق التبعيات، ثم يبني EXE ويجري اختبار تشغيل الحزمة ببيانات اصطناعية معزولة. بعد نجاحها يسجّل SHA-256 ورقم الالتزام في `SHA256SUMS.txt` و`build-manifest.json`، ويصدر إثبات منشأ البناء في GitHub. ينشر مسار main إصدارًا قابلًا للتنزيل بعد نجاح هذه الخطوات.

إثبات منشأ GitHub وبصمة الملف مستقلان عن توقيع Authenticode الذي تتعرف إليه Windows. لا تُنسب الحزمة إلى شهادة الجهة ما لم يُوفَّر مفتاح وشهادة توقيع معتمدان؛ لا توجد شهادة جهة مرفقة بالمستودع.

## للمطوّر

استخدم `npm ci --ignore-scripts` ثم `npm run check` و`npm test`. البناء المحلي: تثبيت Electron، ثم `npx electron-builder install-app-deps` و`npm run dist:win`. لا تنشر بناءً محليًا على أنه اجتاز مسار Windows ما لم تُراجع نتائج الالتزام نفسه.
