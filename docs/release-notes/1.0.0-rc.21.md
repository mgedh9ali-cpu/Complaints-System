يحمل هذا الإصدار تحسينات main المدمجة في طلبات السحب 75 إلى 78. تشمل إصلاح إضافة الملاحظات الداخلية، وتسريع تسجيل الدخول وتوليد رقم السجل، وتقليل قراءة بيانات الأرشيف وتشفيرها عند تعديل سجل.

يتضمن مسار التحقق اختبار ترقية من المثبّت المنشور للإصدار rc.20. يسجّل الاختبار شكوى واستفسارًا وتواصلًا ببيانات اصطناعية، ثم يتحقق من دخول المالك وبقاء السجلات بأنواعها وأرقامها بعد الترقية.
